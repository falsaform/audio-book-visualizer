# Frontend

Vite + TypeScript + React single-page app for the Audiobook Visualizer web UI.
The API client and [TanStack Query](https://tanstack.com/query) hooks in
`src/gen/` are generated by [Kubb](https://kubb.dev/) from the Django Ninja
OpenAPI schema — don't edit them by hand.

## Develop

```bash
npm install
npm run openapi    # python -m audiobook_visualizer.web.api > openapi.json
npm run generate   # kubb -> src/gen (types, client, react-query hooks)
npm run dev        # vite dev server on :5173, proxies /api + /frames to :8000
```

Run the API separately with `abv web` (or `just web`), which listens on :8000.

## Build

```bash
npm run build      # -> dist/ (served as static files by the Django app)
npm run typecheck  # tsc --noEmit
```

## Regenerating the client

Whenever the API changes, re-export the schema and regenerate:

```bash
npm run openapi && npm run generate
```
