# Frontend

Vite + TypeScript + React single-page app for the Audiobook Visualizer web UI.
The API client and [TanStack Query](https://tanstack.com/query) hooks in
`src/gen/` are generated by [Kubb](https://kubb.dev/) from the Django Ninja
OpenAPI schema — don't edit them by hand. Package manager: **pnpm**.

## With `just` (runs pnpm in a Node container — no host Node needed)

From the repo root:

```bash
just frontend install
just frontend build        # pnpm install + kubb generate + vite build -> dist/
just frontend dev          # Vite dev server on :5173, proxies /api + /frames to :8000
just frontend typecheck
just openapi               # refresh openapi.json after API changes (Python image)
```

Run the API separately with `abv web` (or `just web`) on :8000.

## With pnpm on the host

```bash
pnpm install
pnpm run openapi    # python -m audiobook_visualizer.web.api > openapi.json
pnpm run generate   # kubb -> src/gen (types, client, react-query hooks)
pnpm run dev        # or: pnpm run build  (-> dist/, served by the Django app)
pnpm run typecheck
```

## Regenerating the client

Whenever the API changes, refresh the schema and regenerate:

```bash
just openapi && just frontend generate     # (or: pnpm run openapi && pnpm run generate)
```
